My Funds in your Dock

Open your portfolio in its own window, with access to saved holdings even when you’re offline.

Safari on Mac (macOS Sonoma 14 or later): choose File → Add to Dock, name it My Funds, then click Add. In Chrome or Edge, use the install app option in the address bar or browser menu.

Bring your portfolio with you: use Data & backup → Export JSON before installing. If the new app opens empty, choose Import JSON inside it, or enter your existing cloud sync key. Safari’s Dock app has separate storage.

For reliable access, install from your usual HTTPS website. A local installation needs the same address and port; keep the local server running for the first launch and updates.
